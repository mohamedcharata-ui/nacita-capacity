# NACITA Capacity Plan

Supply-chain capacity plan for NACITA (warehouses, last mile, fleet, customer plans).

| Page | Who it's for | What it does |
|---|---|---|
| `index.html` | Everyone (share this link) | Read-only view of the latest published data |
| `admin.html` | Data owner | Edit data, then **Export data.json** |
| `data.json` | — | The published data the view page reads |

## Publishing an update
1. Open `admin.html`, make changes (they autosave in your browser).
2. Click **⬇ Export data.json**.
3. In this repository: **Add file → Upload files**, drop the new `data.json`, **Commit changes**.
4. The public page shows the new data within a few minutes.
