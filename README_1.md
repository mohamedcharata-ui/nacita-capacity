| Page | Who it's for | What it does |
|---|---|---|
| `index.html` | Everyone (share this link) | Read-only view of the plan, with live daily actuals |

| `admin.html` | Data owner | Edit the whole plan, then **Export data.json** and upload it here |
| `data.json` | — | Published plan data |
| `config.json` | — | Address of the Google Sheet web app that stores daily actuals |
